# SAHARA / САХАРА — бренд-гайд

Публичный гайдлайн и каталог утверждённых материалов бренда.

- Сайт: https://danielretfordit.github.io/sahara-brand-guide/
- PDF: [гайдлайн](SAHARA-brand-guidelines.pdf)
- Полный комплект: [ZIP v1.1](https://github.com/danielretfordit/sahara-brand-guide/releases/download/brand-kit-v1.1/SAHARA-final-brand-kit-v1.1.zip)

Каталог позволяет выбрать несколько макетов и форматы. По умолчанию скачиваются отдельные PNG-файлы. Переключатель «Файлы / ZIP-архив» позволяет собрать выбранное в ZIP. Все файлы размещены здесь; сервер и внешние CDN не требуются. JSZip распространяется с лицензией в `vendor/`.

Исходные логотипы и набор файлов сохранены. Контактные шаблоны требуют заполнения фактических данных.
